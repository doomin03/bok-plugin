# 플러그인 변경 리뷰

## 반영한 오너 요청

문서 준비에서 비교 리뷰 생성 -> 오너 판단 -> bok-spec으로 OpenSpec 반영 -> 범위 선택 -> 구현 -> 검증 순서.
기존 유사 차트 재사용과 신규 차트 생성은 별도 전략으로 기록한다. 신규 차트는 기존 chartDraw/Highcharts 개발 방식을 사용하며, 정확히 같은 donor가 없다고 구현 불가 처리하지 않는다.
원본 통계 그림은 비교 증거 전용이다. 미구현 차트의 이미지 대체는 금지한다.

## 구현 내용

- bok-start / bok-spec / bok-chart / bok-verify / bok-feedback 역할 분리.
- 이전 통화신용정책 feature 브랜치의 코드 패턴을 차트 스킬에 기록.
- workflow.mjs: 리뷰 초안 보존, 명시적 계획 개정, 오너 결정의 버전별 OpenSpec, 선택 단위 승인 검사.
- tickets.mjs: 구현 선택 및 등록 명령에 오너 승인 검사 연결, Jira와 로컬 OpenSpec 연결.
- render-comparison.ps1: 비교 이미지를 OpenSpec evidence 경로로만 렌더링.
- 전체 사이트 실험 생성기는 활성 패키지에서 제외하고 로컬 .verification/retired에 보존.
- README 설치/명령/범위/리뷰 절차 정리. 프로젝트 설치로 Codex와 Claude 모두 갱신.

## 검증

- Node 테스트 13개 통과: 범위·중복 등록·불명확한 응답·리뷰·무결성·승인·보류·원본 변경·계획 개정.
- Python 추출 테스트 2개 통과.
- 11개 스킬 frontmatter 및 플러그인 manifest 검증 통과.
- Jira 실제 서버 등록은 실행하지 않았으며 통합 검증은 남아 있음.
- 신규 차트 전략의 승인 흐름은 테스트했으나 이번 실차트 품질 검증은 재사용 경로 한 건뿐. 신규 복합 차트 품질까지 검증했다고 주장하지 않음.

## 단일 차트 테스트

사용자가 그림 I-1의 기존 차트 재사용을 승인했다. 기존 feature 브랜치 차트와 같은 계열·축 구조를 확인했다.
44개월과 132개 원본 값 일치. 데스크톱/375px에서 live Highcharts 값·축·원본 이미지 미사용·가로폭·화면 재진입 검증.
원본 그림의 회색/색상 자체를 복제하는 것이 아니라 이전 웹 보고서의 스타일을 유지했다. 원문은 계열·값·기간·단위·명세 검증 근거로 사용했다.
최종 시각 결과는 오너 리뷰 대기.

알려진 참고: 기존 report.html도 1280px 뷰포트에서 페이지 컨테이너 폭이 1290px이다. 공통 스타일 변경 없이 그대로 두었다. 차트 자체는 화면 내에 들어가며 375px에서는 페이지 넘침이 없다.
동일 차트가 기존 세계경제 섹션과 테스트 섹션에 연결되어 검수 빌드에 두 차트 ID가 표시될 수 있다. 같은 컴포넌트에 대한 ID이며 차트가 중복 렌더링된 것은 아니다.

## 범위와 보존

이번 푸시는 플러그인 저장소만 대상으로 한다. Vue 저장소의 미완성 전체 보고서, 사용자 지침, 원본 DOCX/XLSX/추출 XML/이미지는 포함하지 않는다.
기존 사이트 작업물은 보존하고, 단일 차트 URL에서만 I-1을 따로 검토한다.
